Luruskan Pemahaman

Mitos vs Fakta di Pemda

MITOS

"Kualitas data sepenuhnya adalah urusan orang IT di Diskominfo."

FAKTA

Diskominfo menyediakan infrastruktur & standar (Walidata), namun akurasi substansi data lahir di hulu pada OPD Produsen Data dan petugas lapangan.

MITOS

"Semakin banyak aplikasi baru dibuat, data otomatis semakin rapi."

FAKTA

Membuat aplikasi terpisah tanpa standar metadata justru menciptakan silo data (data terkotak-kotak dan duplikat). Utamakan integrasi API.

MITOS

"Pembersihan data cukup dilakukan setahun sekali saat penyusunan LKPJ."

FAKTA

Data penduduk dan sosial bersifat dinamis (kelahiran, kematian, pindah). Validasi harus berlangsung berkelanjutan dan terhubung langsung dengan database induk.
